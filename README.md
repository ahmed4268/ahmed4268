### 🚀 What I'm working on

**RFIDIA — Cashless Event Platform → Multi-tenant SaaS**
NFC/RFID cashless payment system for events, being rebuilt into a multi-tenant SaaS product. Spring Boot modular monolith backend, Supabase/PostgreSQL, separate Flutter Staff and Guest PWA apps.

**LanceHub**
A freelance marketplace built on Spring Boot microservices, Angular, Keycloak, and Docker — with gateway-owned JWT auth, full registration/session flows, and a modular domain design (Users, Projects, Gigs, Contracts, Messaging, Tickets).

**Projet Italie**
RFID item-level traceability platform for garment manufacturing (supplying Decathlon), deployed on Azure — Container Apps, PostgreSQL Flexible Server, Key Vault, with hardened multi-reader middleware for factory floors.

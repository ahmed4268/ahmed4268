# How to install this profile README

GitHub shows a README at the top of your profile when it lives in a repository
**named exactly the same as your username**.

## 1. Create the repo

Create a new public repository called **`ahmed4268`** — the name has to match
your username character for character. Tick "Add a README file"; GitHub will
show a note confirming you have found the secret profile repo.

## 2. Add the files

Copy into the new repo:

```
README.md                        →  README.md
.github/workflows/snake.yml      →  .github/workflows/snake.yml
```

Commit and push to `main`.

## 3. Turn on the snake animation

The contribution-graph snake at the bottom is generated by a scheduled action,
not a static image — the file it points at does not exist until the workflow has
run once.

1. Open the **Actions** tab on the `ahmed4268` repo.
2. If prompted, enable workflows for the repository.
3. Select **Generate snake animation** and click **Run workflow**.
4. Wait for it to go green. It creates an `output` branch holding `snake.svg`.

After that it refreshes itself every six hours. Until the first run completes,
that one image will show as broken — everything else works immediately.

If the workflow fails with a permissions error, go to
**Settings → Actions → General → Workflow permissions** and select
**Read and write permissions**.

## 4. One thing to change

The portfolio badge near the top points at a placeholder:

```
https://ahmed4268.github.io/portfolio/
```

Swap it for the real URL once the portfolio site is deployed. It is marked with

## What is rendered by an external service

Everything below is fetched live when someone opens your profile. None of it
needs an API key, but all of it depends on a third party being up — which is
worth knowing if a panel ever shows as broken.

| Element | Service |
|---|---|
| Animated typing header | `readme-typing-svg.demolab.com` |
| Technology badges | `img.shields.io` |
| Profile view counter | `komarev.com` |
| Stats and top languages | `github-readme-stats.vercel.app` |
| Streak panel | `streak-stats.demolab.com` |
| Contribution activity graph | `github-readme-activity-graph.vercel.app` |
| Snake animation | your own `output` branch, via `Platane/snk` |

The stats panels use transparent backgrounds (`bg_color=00000000`), so they sit
correctly in both GitHub's light and dark themes.

### ⚠️ The stats panels need self-hosting to be reliable

I checked every one of these while writing this. All of them responded except
**`github-readme-stats.vercel.app`**, which returned `503 Service Unavailable`
on every attempt.

That is not a mistake in the URL — it is the well-known problem with that
project's *shared* public instance: everyone's profile hits one deployment, it
burns through its GitHub API quota, and it starts refusing requests. It
recovers, then fails again.

The two panels affected are **GitHub stats** and **Top languages**. The fix the
project itself recommends is to deploy your own instance, which takes a couple
of minutes and is free:

1. Go to [github.com/anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats)
   and click **Deploy to Vercel** (or fork it and import the fork on Vercel).
2. Create a GitHub personal access token with **no scopes** (public data only).
3. In the Vercel project, add an environment variable `PAT_1` set to that token.
4. Deploy, then replace `github-readme-stats.vercel.app` in `README.md` with
   your own domain — for example `ahmed-stats.vercel.app`.

If you would rather not bother, just delete those two `<img>` tags. The typing
header, badges, streak panel, activity graph and snake all work without them.

## Editing the typing header

The header text is URL-encoded in the image link. Lines are separated by `;`,
and `%20` is a space, `%E2%80%94` an em dash, `%C2%B7` a middle dot. To change
it, edit the `lines=` parameter — or rebuild the URL at
[readme-typing-svg.demolab.com](https://readme-typing-svg.demolab.com).
